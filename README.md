## 🧠 What is Synapse?

**Synapse is a foundation that brings together multiple Roblox Studio plugins under one ecosystem.**

Rather than being a single plugin, Synapse is designed as a growing collection of tools — each focused on solving a specific part of the development workflow.

The goal is simple: **build professional-grade tools that make creating in Roblox Studio faster, cleaner and more powerful.**

---

## 🛠️ Plugins

### 🎨 Synapse UI Designer

A visual UI creation and animation tool for Roblox Studio.

It provides a workflow inspired by professional design and animation software, including:

- Visual hierarchy / object explorer
- Central UI preview canvas
- Property inspector
- Keyframe-based animation timeline
- Position, size, rotation and color animation
- Easing and interpolation
- Auto-key animation workflow
- Playback, looping and timeline controls
- UI element creation and duplication
- ScreenGui export workflow

The plugin is built around the idea of bringing a more complete **UI design + animation workflow directly into Roblox Studio**.

### 🧩 Synapse UI Animation System

A complementary animation system focused on making UI animations reusable through code.

It allows created animations to be treated as structured animation assets and played from Luau, making it possible to build consistent UI motion across an entire Roblox experience.
