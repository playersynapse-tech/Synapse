# Contributing to Synapse

Thank you for your interest in contributing to Synapse.

## Before contributing

- Keep changes focused and maintainable.
- Preserve the existing Synapse visual and code style.
- Use Luau-compatible syntax.
- Avoid committing generated files, local Studio files, credentials, or private project data.
- Test plugin changes in Roblox Studio before opening a pull request.

## Pull requests

Please include:

- A concise description of the change
- The reason for the change
- Testing performed in Roblox Studio
- Screenshots or recordings for relevant UI changes

Keep pull requests focused on one feature, fix, or improvement whenever possible.

## Code style

Use clear names, small focused modules, consistent formatting, and existing project conventions. Avoid unrelated refactors in feature or bug-fix pull requests.
