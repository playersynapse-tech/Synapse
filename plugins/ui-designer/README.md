# Synapse UI Designer

A visual **UI creation and animation** tool for Roblox Studio.

Build interfaces with a hierarchy, preview workspace, inspector and keyframe timeline in one workflow.

### Features

- Visual UI object creation
- Keyframe-based animation
- Position, size, rotation, color and transparency controls
- Easing style and direction
- Ready-made animation effects
- Animation events and presets
- Auto-key workflow
- Playback, loop and timeline controls
- Undo / redo
- Keyboard shortcuts
- Persistent editor settings
- Save and import workflows
- Reusable UI animation data
