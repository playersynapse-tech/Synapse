# Development Guide

Use Roblox Studio to test and develop Synapse.

## Open the plugin

1. Open Roblox Studio.
2. Open a test place.
3. Go to **Plugins > Manage Plugins**.
4. Click **Load from file**.
5. Select one of these files:
   - `plugins/tool-configurator/SynapseToolConfig.luau`
   - `plugins/ui-designer/SynapseUiDesigner.luau`

## Test

- Load the plugin into Studio.
- Test the workflow in a sample place.
- Check for errors in the Output window.
- Make sure the feature works before opening a PR.

## Rules

- Keep changes focused.
- Follow existing project patterns.
- Avoid unrelated refactors.
- Test everything in Studio before committing.
